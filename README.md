# Midterm Project - Front-End Development

This project was created as a midterm exam for the Front-End Development course.

## Project Overview

This assignment focuses on building a simple and well-structured web page using core front-end technologies such as HTML, CSS, and basic page layout techniques. The goal is to demonstrate understanding of semantic structure, styling, and content organization.

## What This Project Includes

- A homepage layout
- A profile page
- Clean and readable styling
- Structured content using HTML and CSS
- Hover effects for interactive elements
- Meta tags for proper page metadata
- Lists for organized content presentation
- Font import for enhanced typography

## Technologies Used

- HTML
- CSS

## Purpose

The purpose of this project is to show the practical application of front-end development concepts learned during the course, including page design, visual hierarchy, and responsive presentation.
